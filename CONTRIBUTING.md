# Contributing to LoL Arena Wins Tracker

Merci de vouloir contribuer au projet.

## Démarrage rapide

### Prérequis
- Node.js 18+
- npm

### Installation
```bash
git clone https://github.com/Bkh84/lolarena-wins.git
cd lolarena-wins
npm install
```

### Développement
```bash
npm run dev
```

### Vérifications avant PR
```bash
npm run lint
npm run build
```

## Workflow recommandé

1. Créer une branche :
   - `feature/ma-feature`
   - `fix/mon-correctif`
   - `docs/ma-doc`
2. Faire des commits clairs (ex: `feat: add champion filter keyboard shortcut`)
3. Ouvrir une Pull Request avec description des changements

## Règles de contribution

- Garder les changements ciblés et lisibles
- Ne pas inclure d'informations sensibles (IP, credentials, secrets)
- Mettre à jour la documentation si nécessaire
- Respecter le [Code of Conduct](./CODE_OF_CONDUCT.md)
