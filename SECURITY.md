# Security Policy

## Supported Versions

Les versions maintenues reçoivent les correctifs de sécurité :

| Version | Support |
| ------- | ------- |
| 0.x.x   | ✅ |

## Reporting a Vulnerability

Si vous découvrez une vulnérabilité, merci de ne pas ouvrir d'issue publique.

### Contact
- Email : contact@remybaroukh.fr

### Informations utiles
- Type de vulnérabilité
- Fichiers/sections concernées
- Étapes de reproduction
- Impact potentiel
- Proposition de correction (optionnel)

### Délais indicatifs
- Accusé de réception : 48h
- Évaluation initiale : 7 jours
